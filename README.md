# 06 — Projets

Fiches détaillées des projets significatifs réalisés par le candidat, servant de
support principal aux preuves de compétences (voir `05-preuves/projets/`).

Chaque fiche suit le canevas : contexte, objectifs, rôle du candidat,
technologies utilisées, réalisations, résultats, compétences démontrées.
